# Nerd wordmarks

The boot screen of the Nerd boards shows the maker's wordmark under the
WarpAxe logo. `tools/make-splash.py` turns these files into display
sprites:

| File | Boards | Cut from |
|---|---|---|
| `nerdqaxe-plusplus-wordmark.png` | NerdQAxe++ (all revisions) | NerdOS theme `NerdQaxePlus2` |
| `nerdoctaxe-wordmark.png` | NerdOctaxe-γ | NerdOS theme `NerdOctaxeGamma` |
| `nerdaxe-wordmark.png` | NerdAxe Gamma | NerdOS theme `NerdAxeGamma` |
| `nerdqx-wordmark.png` | NerdQX (Q1370, Q1373) | NerdOS theme `NerdQX` |
| `nerdaxe-gaia-wordmark.png` | NerdAxe Gaia | BitMaker theme `NerdAxeGaia` |

Sources, both GPLv3:

- NerdOS: [shufps/ESP-Miner-NerdQAxePlus](https://github.com/shufps/ESP-Miner-NerdQAxePlus),
  `main/displays/images/themes/<theme>/Raw Images/initscreen2.png`;
  shufps agreed to the use of his artwork in
  [issue #710](https://github.com/shufps/ESP-Miner-NerdQAxePlus/issues/710).
- BitMaker's Gaia firmware: [BitMaker-hub/ESP-Miner-NerdQAxePlus](https://github.com/BitMaker-hub/ESP-Miner-NerdQAxePlus),
  tag `gaia-v1.1.1`, `main/displays/images/themes/NerdAxeGaia/Raw Images/initscreen2.png`
  (interface by @bitmaker).

"NerdQAxe", "NerdOctaxe", "NerdAxe" and "NerdQX" are trade marks
registered by solomining.de (Bolt Engineering GmbH) on behalf of OSMU.
They agreed by e-mail on 2026-09-29, first for NerdQAxe++ and NerdOctaxe
and then for NerdAxe (Gamma, Gaia) and NerdQX, that WarpAxe shows the
names and logos on the boot screen of these boards. Bitronics, who make
and sell the NerdAxe Gaia and publish its firmware as BitMaker (the
BitMaker-hub GitHub account links bitronics.store), agreed by e-mail on
2026-09-30 that WarpAxe shows the "NerdAxe Gaia" wordmark on the Gaia's
boot screen.
